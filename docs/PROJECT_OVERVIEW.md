# Project Overview — Wild Snake Adventure

## Aim
To build an interactive browser game that demonstrates how HTML, CSS, and JavaScript can work together to create a playable application.

## Technologies
- HTML for structure
- CSS for styling and responsive presentation
- JavaScript for game logic and interaction
- Canvas API for drawing
- Web Audio API for sound
- Local Storage for saving supported settings and unlocked phases

## Main gameplay loop
1. Read player input.
2. Update the snake's direction and position.
3. Check food collection and collisions.
4. Update the score, timer, hazards, and phase state.
5. Draw the updated game scene.
6. Continue until the phase is completed or the run ends.

## Exhibition talking points
- A grid makes movement and collision checks easier to manage.
- Increasing difficulty makes the phases progressively more challenging.
- Canvas can draw custom graphics without importing a separate sprite sheet.
- Browser APIs make sound, keyboard input, and local persistence possible.
- Responsive CSS allows the interface to adapt to different screen sizes.

## Important note
This overview describes the project at a high level. For the exact implementation, refer to `index.html`.
